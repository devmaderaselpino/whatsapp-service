# El Pino - whatsapp-service

Este es el **backend** de la aplicación **El Pino**, desarrollado con **Node.js** y **AXIOS** para manejar el envio de mensajes  con **META**.

---

## Características

- API  para gestionar **templates** y **envio de mensajes masivos**  
- Manejo de errores y validaciones integradas.
- Conexión con **MySQL** para persistencia de datos.
- Soporte para futuras extensiones y módulos adicionales.

---

## Tecnologías

- **Backend:** Node.js  
- **API REST:** Axios 
- **Base de datos:** MySQL
